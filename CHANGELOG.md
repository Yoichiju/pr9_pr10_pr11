# Changelog

Все значимые изменения в проекте "PR9 Auth" будут документироваться в этом файле.

## [1.0.0] - 2024-11-18
### ✨ Добавлено
- Реализован модуль авторизации по паттерну Clean Architecture + MVI (UDF).
- Добавлен Jetpack Compose UI с кастомной пастельно-розовой темой (Material 3).
- Настроено управление состоянием через `StateFlow` и `ViewModel`.
- Реализована валидация полей в реальном времени (email и длина пароля).
- Добавлен `SnackbarHost` для элегантного отображения ошибок сети.
- Настроен Dagger Hilt для внедрения зависимостей (UseCase в ViewModel, Repository в UseCase).
- Экран профиля (`HomeScreen`) с отображением данных пользователя и кнопкой выхода.

### 🐛 Исправлено
- Исправлена несовместимость версий JVM: жестко задан `jvmTarget = 17` для избежания конфликтов KSP и JavaCompiler.
- Удален устаревший атрибут `package` из `AndroidManifest.xml` (теперь управляется через `build.gradle.kts`).
- Увеличен лимит памяти Gradle Daemon до 2GB (`-Xmx2048m`) для предотвращения сбоев при компиляции Compose и KSP.
- Удален шаблонный `ExampleInstrumentedTest.kt`, вызывавший ошибки линковки при отсутствии зависимостей androidTest.

### ⚙️ Изменено
- Обновлены версии плагинов: Kotlin 2.0.21, Hilt 2.51.1, KSP 1.0.28, Compose BOM 2024.09.00.
- Переход с `kapt` на `ksp` для ускорения генерации кода Hilt.
